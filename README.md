# Sense Director

유튜브 링크나 로컬 영상에 포인트와 그림으로 수정 요청을 남기는 영상 검수 도구입니다. 캡처·주석·댓글을 HTML 파일 하나로 공유할 수 있습니다.

**바로 쓰기:** https://osense.github.io/Sense-Director/

OSNS.studio 제작.

## 내 컴퓨터에서 실행

Windows와 Node.js가 필요합니다. 따로 설치할 패키지는 없습니다.

1. 저장소를 내려받습니다.
2. `Sense Director 실행.cmd`를 더블클릭합니다.
3. 브라우저에서 `http://127.0.0.1:8765/`를 엽니다.
4. **대상 영상** 메뉴에서 유튜브 링크나 영상 파일을 선택합니다.

실행 창은 작업하는 동안 열어 두세요. 유튜브 장면을 캡처하려면 **탭 캡처 연결**에서 현재 검수기 탭을 선택해야 합니다.

## 기능

- 영상 시간·위치에 포인트나 자유로운 그림 주석 추가
- 앱 안에서 재생·일시정지·FPS 기준 프레임 이동
- 장면 캡처와 프로젝트 JSON 저장·복원
- 큰 이미지, 주석·댓글 패널, 필름 롤을 갖춘 공유 HTML
- 공유 HTML에 댓글 작성, 댓글을 포함한 HTML 다시 저장
- 카톡용 텍스트 복사: 시간, X/Y 좌표, 유튜브 시점 링크
- HTML 보고서 인쇄·PDF 저장

유튜브 프레임 이동은 설정한 FPS 기준의 근사 이동입니다. 공유 HTML을 파일로 직접 열면 안쪽 유튜브 재생이 제한될 수 있으며, 이때는 해당 시점의 유튜브 링크를 씁니다. 댓글은 브라우저에 보관되므로 다른 사람에게 전달하려면 **댓글 포함 HTML 저장**으로 내려받은 파일을 공유하세요.

자세한 사용 방법은 [사용방법.md](사용방법.md)를 참고하세요.

## 개발 검증

Google Chrome과 실행 중인 로컬 서버가 필요합니다. Chrome 경로는 `CHROME` 환경변수로 바꿀 수 있습니다.

```
node review-server.cjs --no-browser
node review.test.cjs            # 다른 터미널에서
node review.test.cjs --youtube  # 실제 유튜브 재생·캡처까지 (인터넷 필요)
```
