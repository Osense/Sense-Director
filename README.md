# 쎈스 디렉터 · Sense Director

디렉터와 클라이언트가 영상 수정요청을 핀과 펜으로 주고받는 검수 도구입니다.

**바로 쓰기:** https://osense.github.io/Sense-Director/

WesNS 제품 (Wes & Osense).

## 흐름

1. **디렉터 콘솔**: 유튜브·비메오 링크나 mp4 주소를 붙여 넣거나 영상 파일을 올리면 프로젝트가 생깁니다. 화면비와 프레임 수는 알아서 맞춥니다. 프로젝트 이름, 클라이언트 안내사항, 마감일을 적습니다.
2. **공유**: 핀 번호 4자리가 자동으로 만들어지고 클라이언트 링크가 생깁니다. 주소 복사, 카톡·메시지용 복사, 공유하기, QR을 쓸 수 있습니다.
3. **클라이언트 화면**: 핀 번호를 넣고 들어와 안내사항을 확인합니다. 핀을 찍거나 펜으로 그리면 오른쪽에 시간 주소(시:분:초:프레임)가 붙고, 바로 내용을 적습니다. 작업 중에는 화면 공유를 쓰지 않아 지연이 없습니다.
4. **수정요청 보내기**: 오른쪽 위 버튼으로 보냅니다. 이때 장면 사진을 한 번에 만듭니다(영상 주소·파일은 바로, 유튜브·비메오는 이 탭 화면 공유를 잠깐 켰다 끕니다). 전송이 안 될 때는 메시지, HTML, PDF로 보냅니다.
5. **디렉터 안내**: 디렉터도 같은 영상에 핀·펜으로 안내를 남깁니다(노란 D1, D2). 클라이언트 링크에 담겨 클라이언트 화면의 "디렉터 안내" 탭과 영상 위에 보이고, 클라이언트가 답글을 달 수 있습니다.
6. **환류**: 디렉터는 항목마다 상태(대기·진행 중·반영·보류)와 댓글을 달고 "회신 보내기"로 돌려보냅니다. 클라이언트는 "보낸 요청"에서 확인하고 답글을 달 수 있습니다.

## 시험 버전(서버 없음)

지금은 서버 없이 동작합니다.

- 프로젝트 정보는 클라이언트 링크 안에 압축되어 들어갑니다. 핀 번호는 링크에 넣지 않고 확인용 값만 넣습니다. 핀 확인은 브라우저 안에서만 이뤄지므로 실제 보안이 필요하면 서버를 붙여야 합니다.
- 같은 브라우저에서는 디렉터 콘솔과 클라이언트 화면이 실시간으로 이어집니다.
- 영상 파일 올리기는 서버 대신 이 브라우저(IndexedDB)에 저장합니다. 다른 기기의 클라이언트는 같은 파일을 직접 골라 연결하며, 크기가 다르면 다른 편집본일 수 있다고 알려 줍니다.
- 다른 기기 사이에서는 링크로 주고받습니다. 클라이언트의 메시지에 든 `#r=` 링크나 HTML 파일을 디렉터 콘솔의 **가져오기**(또는 끌어 놓기)로 넣고, 디렉터의 회신 링크를 열면 클라이언트 화면에 상태와 댓글이 들어갑니다.
- 디렉터 콘솔은 처음 열 때 WesNS 로그인 창을 띄웁니다(목업: 아무 이메일 + 8자 이상 비밀번호, 카카오·네이버 버튼). 로그인 정보는 WesNS 사이트와 같은 `wesns.mock.user`에 저장되므로, 같은 osense.github.io에서 WesNS 사이트에 로그인해 두었다면 건너뜁니다. 클라이언트 화면은 핀 번호만으로 들어옵니다.
- 저장소는 `assets/js/store.js` 한 곳에 모여 있어 나중에 서버로 바꾸기 쉽습니다.

## 화면비·프레임 수 자동 판단

- 영상 주소·파일: 영상 크기로 화면비를 정하고, 재생하는 동안 프레임 간격을 재서 프레임 수(23.976~60)를 정합니다.
- 유튜브·비메오: 쇼츠 여부·영상 정보·플레이어가 알려 주는 크기로 화면비를 정합니다. 프레임 수는 제목에 fps가 있으면 그 값, 없으면 30fps 기준이며 디렉터가 설정에서 바꿀 수 있습니다.
- 유튜브·비메오 장면 사진은 브라우저 보안상 보낼 때 "이 탭 화면 공유"를 한 번 허용해야 찍힙니다(크롬·엣지 컴퓨터). 허용하지 않거나 휴대폰이면 사진 없이 보내며, 시간 주소와 핀·그림은 그대로 남습니다. 디렉터도 수신함에서 사진 없는 항목의 장면 사진을 만들 수 있습니다.

## 디자인

- WesNS 사이트 톤: Pretendard, 밝은 화면 기본 + 다크 모드(사이트와 같은 설정 `wesns.theme`), 중성 회색, WesNS 브랜드 그라디언트, 둥근 카드. 이모지 대신 선 아이콘.
- 주석 색은 테마와 관계없이 고정 — 클라이언트는 버밀리온, 디렉터는 파랑. 핀과 펜은 쎈스 초크 투톤 펜처럼 흰 테두리 위에 본색(60% 굵기)을 얹어 어떤 장면 위에서도 읽힙니다.

## 단축키

`Space`/`K` 재생·정지 · `,` `.` 1프레임 · `←` `→` 1초(Shift 5초) · `J` `L` 5초 · `P` 핀 · `D` 펜 · `M` 메모만 · `?` 사용법

## 내 컴퓨터에서 실행

Node.js가 필요하고, 따로 설치할 패키지는 없습니다. `Sense Director 실행.cmd`를 더블클릭하거나 `node review-server.cjs`를 실행한 뒤 `http://127.0.0.1:8765/`를 엽니다.

## 문서 검수 (PDF · PPT · 사진)

영상뿐 아니라 PDF, PowerPoint(.pptx), 사진(여러 장을 한 세트로)도 올려 검수할 수 있습니다.

- 문서는 '쪽이 시간인 플레이어'로 다룹니다. 시간 주소 대신 `3쪽`, `슬라이드 3`, `사진 3`이 붙고, 핀·그림·카드·보내기·받은함·보고서는 영상과 똑같이 동작합니다.
- 재생 줄은 없고 아래 줄에 표시 도구(핀·펜·이동·메모), 쪽 넘기기, 확대가 있습니다. 왼쪽에 쪽 목록(쪽마다 요청 수 표시)이 붙습니다.
- 확대: Ctrl(⌘) + 휠, 트랙패드 집기, 두 손가락, `+ − 0` 키, 아래 확대 버튼. 확대하면 오른쪽 아래 미니맵이 나타나 보는 자리를 옮길 수 있고, 이동(H) 도구나 마우스 가운데 버튼으로 끌어서 옮깁니다. 확대한 채로 그리면 더 촘촘한 좌표로 기록되고, PDF는 확대에 맞춰 선명하게 다시 그립니다.
- 쪽 사진은 표시하는 순간 바로 만들어집니다(화면 공유 없음). 쪽마다 크기가 달라도 카드 비율이 맞습니다.
- PPT는 브라우저에서 직접 그리므로 글꼴·도형이 원본과 조금 다를 수 있습니다. 정확히 보려면 PDF로 저장해 올리세요. 예전 `.ppt` 형식은 열 수 없습니다.
- 라이브러리(PDF.js, pptx-preview, modern-screenshot)는 `assets/vendor/`에 들어 있고, 해당 문서를 열 때만 불러옵니다.

## 언어

한국어와 영어를 지원합니다. 상단의 언어 버튼(EN / 한국어)으로 바꾸며, 선택은 WesNS 사이트와 같은 `wesns.lang`에 저장됩니다. 처음에는 브라우저 언어를 따릅니다.

- 화면 문장은 한국어 원문을 그대로 `t('…')`로 감싸 두고, `assets/i18n/en.js`가 원문 → 영어를 담습니다.
- 새 언어는 `assets/i18n/<코드>.js`를 만들고 `assets/js/i18n.js`의 `LANGS`·`PACKS`에 추가하면 됩니다. 번역이 빠진 문장은 원문으로 보이고 `window.__i18nMissing`에 모입니다.

## 구성

```
index.html            앱 껍데기
assets/app.css        WesNS 디자인 톤
assets/js/app.js      라우터 (#c= 클라이언트, #r= 수정요청 가져오기, 그 밖은 디렉터 콘솔)
assets/js/director.js 디렉터 콘솔
assets/js/client.js   클라이언트 화면
assets/js/viewer.js   재생 화면·주석 도구 (공통)
assets/js/player.js   유튜브·비메오·영상 주소·파일 플레이어, 장면 사진, 화면비·fps 판단
assets/js/media.js    영상 파일 보관 (지금은 브라우저 저장 목업)
assets/js/doc.js      PDF·PPT·사진 렌더링 (쪽 = 시간)
assets/vendor/        PDF.js · pptx-preview · modern-screenshot
assets/js/exports.js  링크·메시지·HTML·PDF
assets/js/store.js    저장소 (지금은 브라우저 저장소 목업)
assets/js/auth.js     WesNS 로그인 (목업)
assets/js/i18n.js     언어팩 불러오기·t()
assets/i18n/en.js     영어 언어팩
```

